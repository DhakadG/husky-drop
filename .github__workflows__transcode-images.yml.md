## Findings

### LOW · Install pillow-heif like the share-previews workflow does

**Where:** 26-27 · **Category:** correctness · **Confidence:** 0.7

**When:** An image-archive job over iPhone HEIC photos.

**Result:** This workflow installs only Ubuntu's libheif, which lacks the HEVC decoder ('Unsupported codec'); image-decode.mjs then falls back to pillow-heif, which is not installed here, so every such HEIC fails while the same files decode fine in transcode-share-previews.yml.

**Fix:** Add libheif-plugin-libde265 and `python3 -m pip install --break-system-packages pillow pillow-heif`, mirroring transcode-share-previews.yml.
